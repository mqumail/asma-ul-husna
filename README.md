# asma-ul-husna
A Flutter app to learn the 99 names of Allah, one name a day, with home screen widgets. Built in public.

## Why
One name a day, locked for 24 hours so it sinks in, on your home screen.

## Status
🚧 Phase 1: research and UX. See the project board.

## Planned features (v1)
- One name of Allah unlocked each day, in Arabic with transliteration and meaning
- How to call on Allah by that name in your duas
- Home screen widget on Android and iOS
- Daily reminder at a time you choose
- Progress grid of all 99 names
- Works offline, no account, no ads

Full scope: [docs/v1-scope.md](docs/v1-scope.md)

## Tech
Flutter (Android and iOS), native home screen widgets.
